TU SEGURIDAD DIGITAL ES IMPORTANTE

La ciberseguridad empieza con vos, aprendé los conceptos básicos.

Conocé las amenazas del mundo digital

En internet existen distintas amenazas que pueden poner en riesgo nuestros datos, dispositivos y cuentas. Algunas buscan engañarnos para obtener información, mientras que otras utilizan programas maliciosos para causar daños. Conocer sus diferencias es el primer paso para prevenirlas.

En un mundo cada vez más conectado, la ciberseguridad no es solo una tarea, sino una responsabilidad de todos.

Tipos de Amenazas Digitales

Phishing

Engaños que buscan robar información personal mediante mensajes o sitios web falsos.

Ejemplo cotidiano

Un correo falso que dice que tu cuenta bancaria será bloqueada si no ingresás a un enlace.

Malware

Software malicioso diseñado para dañar dispositivos, espiar o robar información.

Ejemplo cotidiano

Una aplicación sospechosa que instala un programa sin que lo sepas.

Ransom
ware

Un tipo de malware que bloquea el acceso a archivos y exige un pago para recuperarlos.

Ejemplo cotidiano

Una computadora cuyos documentos quedan inaccesibles después de una infección.

Ingeniería
social

Técnicas de manipulación que buscan que una persona revele información o realice una acción.

Ejemplo cotidiano

Alguien se hace pasar por soporte técnico para pedirte tu contraseña.

Virus

Software malicioso que se adhiere a un archivo legítimo, replicándose y propagándose cuando se ejecuta.

Ejemplo cotidiano

Descargar un archivo infectado que activa el virus y afecta a otros programas.

Troyano

Malware que se hace pasar por un programa legítimo pero oculta funciones maliciosas para espiar o robar datos.

Ejemplo cotidiano

Instalar un supuesto juego gratuito que oculta un acceso no autorizado al equipo.

No todas las amenazas digitales funcionan igual

Engaños y manipulación digital

Los engaños digitales buscan manipular a las personas para que revelen información privada, realicen alguna acción o permitan el acceso a sus cuentas o dispositivos. Una de las técnicas más conocidas es el phishing, que consiste en hacerse pasar por una persona, empresa o institución confiable mediante mensajes, correos electrónicos o sitios web falsos. Por ejemplo, alguien puede recibir un mensaje que parece ser de su banco y que le pide ingresar a un enlace para verificar sus datos.

Este tipo de ataque forma parte de la ingeniería social, que consiste en aprovechar la confianza, el apuro o la preocupación de una persona para conseguir información o acceso sin autorización. Estos engaños no siempre instalan programas maliciosos: a veces, su objetivo es obtener contraseñas, datos personales o información bancaria. Sin embargo, también pueden utilizarse para engañar a alguien y lograr que descargue un archivo dañino.

Software malicioso: malware, virus, troyano y ransomware

El malware es un término general que se utiliza para describir programas o software diseñados para realizar acciones dañinas, como robar información, alterar archivos o afectar el funcionamiento de un dispositivo. Dentro de esta categoría existen distintos tipos, entre ellos los virus, los troyanos y el ransomware.

Los virus pueden copiarse e incorporarse a otros archivos o programas para propagarse cuando estos se ejecutan. Los troyanos, en cambio, se presentan como archivos o programas aparentemente legítimos, pero ocultan funciones maliciosas. El ransomware también es un tipo de malware: puede bloquear el acceso a archivos o cifrarlos y exigir un pago para intentar recuperarlos.

Estos programas pueden llegar a un dispositivo por diferentes medios, como archivos adjuntos, descargas o aplicaciones comprometidas. En algunos casos, los atacantes utilizan técnicas de phishing o ingeniería social para convencer a la víctima de que abra un archivo o visite un enlace. Por eso, los engaños y el malware pueden estar relacionados: un engaño puede ser la puerta de entrada para que un programa malicioso llegue al dispositivo.
